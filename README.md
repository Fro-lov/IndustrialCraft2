# IndustrialCraft 2 (onter_ic2) — Minecraft 1.21.1 NeoForge

Полноценный порт и современная реализация классического **IndustrialCraft 2 (1.7.10)** для **Minecraft 1.21.1 (NeoForge)** с поддержкой JEI, KubeJS и FTB Quests.

## Особенности
- **Механизмы (Tier 1-2):** Дробитель, Электропечь, Компрессор, Экстрактор, Металлоформовщик (с режимами Прокат, Выдавливание, Резка).
- **Генераторы:** Классический твердотопливный генератор.
- **Солнечные панели:** Базовая, Продвинутая, Гибридная, Ультимейт и Квантовая панель с интерактивным GUI и слотами для зарядки аккумуляторов.
- **Энергохранилища:** BatBox (40k EU / 160k FE), CESU (300k EU / 1.2M FE), MFE (4M EU / 16M FE), MFSU (40M EU / 160M FE) с аутентичным GUI и поддержкой улучшений.
- **Провода:** Медный, Золотой, Высоковольтный, Стекловолоконный и Сверхпроводящий кабель с динамическими multipart 3D-моделями и сетевой передачей энергии.
- **Улучшения:** Ускорители (Overclockers), Хранилища энергии, Трансформаторы.
- **Предметы и ресурсы:** Схемы, композиты, углепластик, иридий, саннариум, резина, аккумуляторы и кристаллы.
- **Интеграция:** Полная поддержка JEI со всеми категориями рецептов.
- **Звуковое сопровождение:** Оригинальные звуковые эффекты работы механизмов IC2.

## Сборка
```bash
./gradlew build
```
Готовый JAR-файл будет создан в `build/libs/onter_ic2-1.0.2.jar`.
